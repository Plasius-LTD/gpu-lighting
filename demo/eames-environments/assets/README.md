# Room reference asset

`finalscene.glb` is the original user-supplied room model, approved by the user
for committing to the public repository on 28 September 2026. It is not a
replacement/proxy for the Eames model: the demo composes both assets.

- 651,696 bytes; glTF 2 binary; 73 primitives; 3,672 triangles.
- SHA-256: `125331dadb83664e978a8c12cc974bae81bb7b75457e290c6063d921bbe11bc5`.
- One embedded image; no authored cameras, lights or emissive materials.
- Source binary and inert exporter provenance are preserved unchanged.
- Loading uses the existing GPU-native shared loader, with no external viewer
  or prohibited runtime dependency.

The file is a demo asset, not included in the npm runtime package. No unrelated
files from the user's source project are included.
